# 삼국지 쇼츠 만들기

채널: 유튜브 "삼국지 한 장면"(@unse_ai, 브랜드 계정), 인스타 @unse.ai. 목적은 unse-ai.com 유입.
비용은 무료·Google AI Pro 안에서만. 사용자와는 한국어, 해요체.

**사용자 확인은 딱 세 번**: ① 대본(episode.json) ② 정지 화면 모음 ③ 완성 영상·게시. 그 사이는 묻지 않고 진행한다.
**검수는 Claude가 매번 직접 한다**: 클립을 받으면 `review.py`로 1초 간격 프레임을 보고, 장면의 `must_show`가 실제로 보이는지 확인한 뒤에만 조립한다. 앞뒤 두 프레임만 보고 넘기지 않는다(2편에서 화살이 눈에 안 꽂힌 채 넘어갔다).
계획 없이 만들면서 고치지 않는다(1편은 지도만 4번 다시 만들었다).

## 0. 준비
- 에피소드 폴더 `docs/videos/epNN/` (assets·work·mp4는 gitignore). 앞 편 폴더를 참고만 하고 복사하지 않는다.
- ffmpeg: 스크립트가 `~/.cache/shorts-tools`에 자동 설치(ffmpeg-static 5.2.0).
- 형식은 `docs/videos/formats.md`에서 고른다(문제→해결→또 문제 / 정사 vs 연의 / TOP3 / 만약에 / 퀴즈). 앞 편과 다른 형식이면 비교가 된다.

## 1. 기획 → 확인 ①
`episode.json`을 쓴다(형식은 `docs/videos/ep02/episode.json` 참고). 6~8장면, 해설 합계 50~90초.
- **사실 대조 먼저**: `src/content/samgukPeople/<id>.ts`의 `historyNote`(정사)·`life`(연의)·`novelVsHistory`. 파일이 없으면 `docs/videos/*.md` 사실표나 위키백과로 확인하고 `facts`에 출처를 적는다.
- 연의 장면은 해설·자막에 "연의에서는". 정사 본문이 아니라 배송지 주면 "옛 기록에는". 숫자 과장 금지("백만 대군" → "수십만 대군").
- 따옴표 대사는 열전 `famousQuote`나 기록에 있는 말만. 아니면 풀어 쓴다.
- 해설은 강사가 들려주는 말투("여러분, …", "그런데요, 여기서…"). "문제 1" 같은 목차식 금지. 첫 문장은 질문·반전(인사 금지).
- 자막은 해설을 줄인 2줄 묶음(`captions`), 한 줄 16자 안팎.
- 장면마다 `must_show`(화면에 꼭 보여야 할 것)를 적는다. 검수 기준이 된다.
- 장면 종류: `clip`(Veo, 움직임이 꼭 필요한 2~3개만, 크레딧 20씩) · `image`(그림+천천히 확대) · `swap`(그림 두 장, `swap_at` 자막 묶음에서 넘어감).
- 끝 화면 `end`: 초상화 1~4명(`public/images/samguk/<이름>.jpg`) + 문구 + 주소. 숫자(참여자 수·순위) 금지.
- 사용자에게는 표(장면·해설·사실 출처)로 보여 주고 확인받는다.

## 2. 그림·영상 (Aside 브라우저) → 확인 ②
**그림 (gemini.google.com, Pro 계정)**
- 새 채팅에 `style_ref` 그림을 붙여 넣고(첫 업로드면 "이미지 권리" 동의 창 → 사용자 승인 필요) 이렇게 요청: "첨부 그림과 완전히 같은 화풍(붓 터치, 색감, 조명, 인물 그리는 방식)으로 새 장면을 세로 9:16으로 그려 줘. 장면: … 글자 금지, 실사 금지, 피 클로즈업 금지." 같은 채팅에서 장면을 이어 요청하면 화풍이 잘 유지된다.
- 붙여넣기: 파일을 `ClipboardEvent('paste')`로 contenteditable에 보낸다. 결과는 가장 큰 `img`를 canvas로 꺼내 Aside 세션 폴더에 저장 후 `assets/`로 복사(Aside는 레포에 직접 못 씀). 결과는 572×1024이고 원본 해상도는 받을 수 없다(기존 장면도 같음).
- 선화가 진하게 나오면 프롬프트 수정보다 기준 그림을 붙여 새 채팅으로 다시 만드는 게 빠르다.
- 지도가 필요하면: Natural Earth(GitHub raw geojson)로 실제 해안선·강을 canvas에 그려 밑그림 → Gemini에 "모양은 그대로, 화풍만" → 지명·화살표는 직접 얹는다. AI에게 땅 모양을 맡기지 않는다. 세력도 예시는 1편(`docs/videos/ep01/assets/map_*`).

**영상 (flow.google.com 프로젝트 `0372bdb2-ef69-480b-bb0e-0863212f5223`, Veo 3.1 Fast)**
- 오른쪽 위 `미디어 메뉴 추가` → 업로드(filechooser) → 에이전트 입력창의 `프롬프트 상자에 소재 추가` → 그림 선택 → `프롬프트에 추가`.
- 프롬프트: "첨부한 이미지를 첫 프레임으로 써서 세로 9:16, 8초 동영상을 Veo 3.1 Fast로 1개 만들어 줘. 그림체(90년대 코에이 삼국지풍 일러스트, 낮은 채도)를 그대로 유지하고 실사로 바꾸지 마. 글자·대사·말소리는 넣지 마. 소리는 … 정도만. 움직임: …"
- 실존 인물 이름(조조 등)을 쓰면 거절된다 → 외모로만 묘사. "오디오를 생성할 수 없음"이면 소리 지시를 현장음 몇 가지로 줄인다.
- 생성 전 "20 크레딧… 승인" 라디오가 뜬다. **사용자가 이번 편 승인을 맡겨야만 클릭**(자동 권한 검사가 막으면 사용자에게 부탁). 뷰포트를 줄이면 오른쪽 채팅창이 사라지니 1440×900 유지.
- **결과가 정해진 동작**(맞는다·꽂힌다·쓰러진다)은 에이전트 대신 직접 생성 화면의 **프레임 모드**로 시작·끝 그림을 둘 다 준다: 입력창 오른쪽 설정 → 동영상 → 프레임 → 9:16 → Veo 3.1 - Fast → x1(20크레딧). `시작`/`종료` 버튼으로 그림을 고르고, 채워진 칸을 누르면 비워진다. 직접 생성은 승인 없이 바로 크레딧이 쓰이니 사용자 승인을 받은 범위만 누른다. 시작 그림만 주면 Veo가 폭력 장면을 빗나가게 순화하기 쉽다.
- 폭력 묘사는 순하게: 맞는 순간은 손으로 감싸 쥐고 손가락 사이로 화살대만 보이게, 피·상처·클로즈업 없음(Veo 필터, 유튜브 연령 제한 회피).
- 완성 영상: 왼쪽 목록의 `[role=group][aria-label="<제목>"]`에 hover하면 `video` src가 생긴다 → fetch로 받는다.
- 정지 화면은 그림들을 한 장으로 붙여 SendUserFile로 보여 주고 확인받는다.

## 3. 음성·조립·검사 (자동)
```bash
node --env-file=.env.local scripts/shorts/tts.mjs docs/videos/epNN   # 해설 전체를 TTS 1회 → 글자 수 비율로 나누기 → 받아쓰기 검사
python3 scripts/shorts/build.py docs/videos/epNN                     # 조립, <name>-small.mp4(30MB 이하)
python3 scripts/shorts/check.py docs/videos/epNN                     # 경계 딸깍·튐·음량·크기
python3 scripts/shorts/review.py docs/videos/epNN                    # 장면 검수: 0.25초 간격 프레임 + 붉은 튐(피) 의심 경고
python3 scripts/shorts/storyboard.py docs/videos/epNN                # 시나리오 검사: 장면별 시작·중간·끝 + 해설 한 장
```
- TTS: 목소리 Charon. 무료 한도는 **모델마다 하루 10회**(태평양 자정 초기화)라 한 편을 한 번 호출로 만든다. 3.x 모델은 지시문을 소리 내 읽으므로 `[warm storytelling]`만 붙인다(스크립트가 처리). 끝 0.15초 0dB 잡음은 자동으로 자른다. 받아쓰기 80% 미만은 `ONLY=s03`으로 그 장면만 다시.
- 한 편 안에서는 같은 모델로 통일한다(모델이 바뀌면 말투가 달라진다).
- **장면 검수(review.png마다)**: ① 첫 프레임이 '시작' 상태인가(처음부터 화살이 박혀 있지 않은가) ② 동작이 한 번만, 해설 순서대로 일어나는가(빼고 다시 박기 같은 되감기 없음) ③ 붉은 튐 경고 프레임을 확대해 피가 없는가.
- **시나리오 검사(storyboard.png)**: ① 같은 사건이 두 번 나오지 않는가(훅에서 결과를 보여 주고 본편에서 또 보여 주지 않기. 훅은 결과 직전에서 멈춘다) ② 인물 연속성(다치기 전 안대 없음, 안대 쪽 일관) ③ 장면마다 해설이 말하는 것이 화면에 있는가 ④ 훅→전개→반전→마무리→끝 화면 흐름.
- 둘 다 통과해야 사용자에게 보낸다. 통과 못 하면 고치고 `ONLY=<id>`로 다시 조립한 뒤 세 검사를 다시 돌린다.
- check가 "문제 없음"이 아니면 고치고 다시 돌린다. sheet.png를 직접 보고 글자 겹침·화풍을 확인한다.

## 4. 확인 ③ → 업로드
- 압축본을 SendUserFile로 보내고, 게시 승인을 받는다.
- 유튜브 스튜디오(채널 UCQvI9qIC3pIq_24_x5XE_3g): `만들기` → `동영상 업로드` → `#select-files-button` filechooser → 제목·설명(`upload`) → `VIDEO_MADE_FOR_KIDS_NOT_MFK` → 다음 3번 → `PUBLIC` → **사용자 승인 후** `#done-button`. "프로모션 만들기"(유료)는 누르지 않는다.
- 인스타 릴스와 인스타 프로필 링크는 웹에서 못 바꾼다 → 사용자에게 앱에서 올려 달라고 캡션을 준다.
- 설명란 링크는 눌리지 않으니 "채널 프로필 링크"로 안내한다. 프로필 링크(utm): 유튜브 `utm_source=youtube&utm_medium=shorts`, 인스타 `utm_source=instagram&utm_medium=reels`, `utm_campaign=<편 이름>`.
