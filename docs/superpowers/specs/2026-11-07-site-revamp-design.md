# 사이트 전체 개편 설계 (2026-11-07)

에이전트 3개(UX 구조, 그로스·검색, 제품 품질 감사)의 제안을 합친 안. URL은 하나도 바꾸지 않는다(네이버 색인·공유 링크 보호). 바꾸는 것은 이름·묶음·순서·결과 사이 연결·제품 품질.

## 1. 구조: "무엇을 넣어서 보나"로 세 줄기
- **생년월일**: 내 사주 풀이 · 2027 신년운세 · 2027 띠별 · 오늘의 운세
- **사진**: 내 관상 풀이 · 동물상 · (삼국지 닮은꼴)
- **둘이 같이**: 얼굴 궁합 · MBTI 궁합 · MBTI 유형 풀이
- 삼국지(닮은꼴·우리 팀·월드컵·열전·영상·일기토)는 "삼국지로 보는 얼굴" 소제목으로 모아 아래에 둔다. 앞에 서지 않는다.

## 3. 홈 순서
헤더(부제 "무료 관상과 내 사주 풀이, 2027 신년운세") → 관상 히어로("사진 한 장으로 읽는 15가지 관상", 버튼 "내 관상 보러 가기") → **시즌 카드를 바로 아래로**(평소 /saju "내 사주, 쉬운 말로 풀어 드려요", 12~1월 /fortune 신년운세) → 띠 칩 → 친구랑 같이(동물상·얼굴 궁합·MBTI 궁합·삼국지) → 쿠팡 → 묶음 탭(12~1월 기본 탭 사주·운세) → FAQ. 하단 중복 띠 칩 목록 제거.
- 시즌 전환은 12/1·2/1 수동 교체(season.ts 한 곳).

## 4. 결과 사이 연결: "같은 줄기 1개 + 다른 줄기 1개"
| 결과 | 같은 줄기 | 다른 줄기 |
|---|---|---|
| 사주 | 2027 신년운세 | 관상 |
| 신년운세 | 내 사주 풀이 | 관상 |
| 띠별 | 신년운세 | 내 사주 풀이 |
| 오늘의 운세 | 내 사주 풀이 | 관상 |
| 관상 | 동물상(같은 사진) | 내 사주 풀이 |
| 동물상 | 관상(같은 사진) | 얼굴 궁합 |
| 삼국지 닮은꼴 | 관상(같은 사진) | 내 사주 풀이 |
| MBTI 유형·궁합 | 오늘의 MBTI 운세 | 내 사주 풀이 |
- 연결 표는 `navigation.ts`의 `NEXT_BY_TEST` 한 곳에. 생년월일 줄기끼리는 재입력 없이(메모리 전달, 저장·URL·GA 금지). 측정은 `next_test_click`.

## 5. 제품 품질 (관상·사주와 같은 기준: 전문성·근거·쉬운 말·기분·결정성)
| 순위 | 제품 | 지금 문제 | 고칠 것 |
|---|---|---|---|
| 1 | 동물상 | "당신!" 문체, 결과 칩에 "질투심·소심함·우유부단·공격적·계산적" 같은 성격 단정, "닮음 70~98%"는 만든 숫자, 연예인 목록, 근거 줄 없음 | 8종 문구를 쉬운 말·기분 원칙으로 재작성, 부정 칩 → 상황+행동 1개, "왜 이 동물상인가요"(측정 특징 2문장), 닮음 %·연예인 삭제 |
| 2 | 오늘의 운세 | 근거 줄에 "갑경충" 같은 용어가 본문에, "가장 힘든 조합"·"건강 신호" 문구 | 근거를 쉬운 문장 + 꼬리 줄로, 힘든·건강 문구를 상황+행동으로 |
| 3 | 2027 띠별 12개 | 본문에 원진·삼합·날삼재, 건강 부위(신장·방광), 월 단위 예언 | 건강 → 생활 습관 한 줄, 삼재·원진은 꼬리 줄, 맨 위 "올해 이 띠는" 쉬운 한 줄 |
| 4 | 얼굴 궁합 | 동물상 표 기반 점수에 임의 가산(jitter), "짝사랑 성공 가능성 %" | % 헤드라인 → "~한 사이" 문장, "왜 이 궁합인가요" 한 줄, jitter 제거 |

| 6 | MBTI | 궁합 가중치 근거 없음, 유형 페이지 "이달의 운세" 수동 갱신 | "어떻게 계산했나요" 접이식, 이달의 운세 제거 |

## 6. 합침·내림 후보 (사용자 결정)
- 오늘의 MBTI 운세: 계산 근거가 없음 → 오늘의 운세에 "MBTI 한마디"로 합치거나 유지.
- 얼굴 궁합: 데이터가 동물상 표 그대로 → 동물상 결과의 "친구와 비교"로 흡수하거나 독립 유지.
- 우리 팀 삼국지: 삼국지 결과 아래 진입점만 남기기.
- 삼국지 일기토: 11/3 보류 결정 → 홈·푸터에서 빼고 허브 맨 끝만.
