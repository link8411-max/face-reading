# 부적 (/bujeok) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 사주·소원·화풍으로 조립되는 부적을 브라우저에서 붓으로 그려 보여 주고, 잠금화면 이미지로 저장하거나 이름을 넣어 링크로 선물할 수 있게 한다.

**Architecture:** 조립 규칙·링크·연출 일정·배너 고르기는 `src/lib/bujeok/`와 `src/lib/zipsise/`의 순수 함수로 두고 테스트로 고정한다. 그림은 `src/components/bujeok/`의 SVG 부품(화풍별 한 벌)이고 서버 호출 없이 클라이언트에서 그린다. 서버가 하는 일은 선물 착지의 메타데이터, 미리보기 이미지, 집시세 신고가 파일 읽기(1시간 캐시)뿐이다.

**Tech Stack:** Next.js 16 App Router, TypeScript, Tailwind 4, SVG + Web Animations API, vitest, Playwright. 새 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-11-11-bujeok-design.md` (구현자는 이 문서와 레포 `CLAUDE.md`를 같이 읽는다)

## Global Constraints

- 서버 비용 0: 부적 그리기·저장·녹화는 전부 브라우저에서 한다. AI 이미지 생성·서버 영상 렌더 금지.
- 효험 단정 금지. 부적 문구에 `반드시`, `100%`, `보장`, `틀림없이`, `들어옵니다`, `합격합니다`가 나오면 테스트 실패.
- 쉬운 말 규칙: 화면 본문에 오행 한자(木火土金水)·십신·간지 용어를 쓰지 않는다. "불의 기운"처럼 쓴다. 전통 화풍 부적 그림 속 길상 한자 글귀는 예외이고 한글 뜻을 옆에 붙인다.
- 한자 글귀는 실제로 쓰이는 문구만: 재물 招財進寶, 합격 金榜題名, 건강 無病長壽, 연애 天生緣分, 액막이 消災吉祥. 지어내지 않는다.
- 이름은 GA·미리보기 이미지·서버 로그에 넣지 않는다. 생년월일은 링크·GA·저장 이미지에 넣지 않고 브라우저 저장소에도 쓰지 않는다.
- 이름 규칙: 앞뒤 공백 제거 후 1~8자, `/^[가-힣A-Za-z0-9 ]+$/`, 금지어 목록에 걸리면 무효.
- 색은 부적 전용 토큰만 쓴다. 옛 민화 색 16진수(`#C41E3A` 등 `tests/design.test.tsx` 68행 목록)를 그대로 쓰지 않는다.
- 글꼴 굵기 900 금지, `next/font/google` 금지(자체 호스팅). 새 글꼴은 OFL만, `scripts/font-subset.mjs`로 서브셋.
- 이모지는 제목·버튼·링크·메뉴에 쓰지 않는다. "○명이 받았어요" 같은 숫자는 넣지 않는다.
- 광고는 부적 아래에만 둔다. 집시세 배너는 실제 데이터만 쓰고, 없으면 쿠팡 배너로 바꾼다.
- 선물 착지는 noindex, canonical `/bujeok`, 사이트맵 제외.
- 커밋은 작업 워크트리 브랜치 `bujeok`에서 한다. main에는 푸시하지 않는다(배포는 사용자 승인 뒤).

## Review Focus

1. **이름에 이모지·`<script>`·9자 이상·공백만** 들어온 링크 → 이름만 떼고 부적은 정상으로 열린다. 화면과 메타데이터에 원문이 그대로 실리지 않는다. (Task 2, Task 6)
2. **변조된 링크 코드**(모르는 화풍, 변형 번호 범위 밖, 조각 수가 다름) → `/bujeok` 시작 화면으로 간다. 오류 화면이 뜨지 않는다. (Task 2, Task 6)
3. **집시세 파일이 깨졌거나 비었거나 필드가 빠졌거나 최근 7일에 0건** → 쿠팡 배너가 대신 뜨고 페이지는 정상이다. (Task 7)
4. **아이폰 사파리·카카오톡 인앱에서 저장** → 길게 눌러 저장 화면이 뜨고, 저장된 이미지의 글자가 화면과 같다(글꼴이 빠져 기본 글꼴로 바뀌지 않는다). (Task 5)
5. **없는 날짜(2월 30일)·범위 밖 연도·음력 윤달** → 안내 문구가 뜨고, 틀린 생년월일로 조용히 다른 부적을 주지 않는다. (Task 1, Task 5)
6. **그리는 도중 "다시 만들기" 연타·건너뛰기** → 선이 겹쳐 그려지거나 반쯤 그려진 채 멈추지 않는다. (Task 4)
