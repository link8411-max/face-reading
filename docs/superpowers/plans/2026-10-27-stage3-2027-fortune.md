# 3단계: 2027 신년운세 + 사주 계산 바로잡기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 12월 검색 시즌 전에 2027 정미년 신년운세와 띠별 운세 12페이지를 배포하고, 틀리게 계산되던 사주(일주·월주·년주)를 바로잡는다.

**Architecture:**
- 사주 계산(`src/lib/saju.ts`)
  - 일주는 한국천문연구원 데이터 기반 `korean-lunar-calendar`로 계산한다.
  - 년주·월주는 입춘·절기 기준(근사 날짜)으로 계산한다.
  - 음력 입력은 양력으로 변환한 뒤 계산한다.
- 2027 운세 데이터: Claude가 작성한 레포 데이터 파일
- 띠별 페이지: 정적 생성(`/fortune/2027/[띠]`)

**Tech Stack:** Next.js 16 App Router, TypeScript, vitest, Playwright, `korean-lunar-calendar@0.4.0`

**Spec:** `docs/superpowers/specs/2026-10-26-unse-ai-revival-design.md` (3단계)

## 발견한 문제 (계획 근거)

- **일주 계산 오류:** 기존 `일주계산`은 1950~2026년 표본 231개 날짜에서 전부 틀렸다(라이브러리 대조). 예: 1950-01-15 코드 을유 / 실제 경술.
- **월주:** 절기가 아니라 양력 월을 그대로 썼다.
- **년주와 띠:** 1월 1일 기준이었다(입춘 기준이어야 함).
- **음력:** 입력해도 변환 없이 양력처럼 계산했다.
- **콘텐츠:** 운세 데이터와 문구가 전부 2026 병오년 기준이다.

## Global Constraints

- 2027년은 정미년(丁未, 붉은 양의 해)이다. 천간 정(화), 지지 미(토)다.
- 입춘은 매년 2월 4일로 근사한다(실제 2월 3~5일). 절기 경계도 매년 같은 근사 날짜를 쓴다(Task 1 표). 근사라는 사실을 코드 주석과 가이드 FAQ에 밝힌다.
- 시주는 계산하지 않는다(기존과 같음). 태어난 시간은 표시만 한다.
- 띠별 페이지 1개당 본문은 1,500~2,000자다. 구성은 총운, 재물, 연애·관계, 직장·학업, 건강, 분기별 흐름(1~4분기), 행운 요소, 조언이다. 월별 12개로 쪼개지 않는다.
- 띠별 페이지 슬러그는 영문이다: rat, ox, tiger, rabbit, dragon, snake, horse, sheep, monkey, rooster, dog, pig.
- 오늘의 운세의 띠 판정도 입춘 기준으로 맞춘다.
- 사용자 사진·개인정보는 저장하지 않는다(기존과 같음). 배포는 사용자 승인 후에만 한다.

## Review Focus

1. **입춘 경계 근처 생일**(2월 3~5일): 년주와 띠가 근사 기준대로 일관되게 나와야 하고, FAQ에 근사라는 안내가 있어야 한다. Task 1 테스트로 확인한다.
2. **음력 윤달·변환 불가 날짜**(음력 2월 30일 등): 오류 안내를 보여야 한다. 조용히 틀린 결과를 내면 안 된다. Task 2에서 다룬다.
3. **1900년 이전·2050년 이후**: 라이브러리 지원 범위 밖이면 안내해야 한다. 입력 범위는 1900~올해라 2050 문제는 없다.
4. **2026년 문구 잔재**: 공유 문구, 파일명, 메타, 구조화 데이터 어디에도 "2026"이 남으면 안 된다. Task 3 테스트로 확인한다.
5. **띠별 페이지의 출생연도 표**: 1~2월생 안내(입춘 전이면 전년도 띠)가 빠지면 독자가 틀린 띠 페이지를 본다. Task 4에서 다룬다.

**Interfaces (produces):**

```ts
export function 년주계산(year: number, month: number, day: number): { 천간; 지지; 띠; 띠이모지 }  // 입춘(2/4) 전이면 전년도
export function 월주계산(year: number, month: number, day: number): { 천간; 지지 }                 // 절기 경계 + 오호둔법
export function 일주계산(year: number, month: number, day: number): { 천간; 지지 }                 // korean-lunar-calendar
export function 띠찾기(year: number, month: number, day: number): string

```

절기 경계 근사(양력, 이 날부터 해당 월지): 1/6 축, 2/4 인, 3/6 묘, 4/5 진, 5/6 사, 6/6 오, 7/7 미, 8/8 신, 9/8 유, 10/8 술, 11/7 해, 12/7 자.
