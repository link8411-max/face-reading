# 밈 능력고사 1차 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/exam/meme`에서 매일 5문제를 풀고 성적표를 받아 공유·친구 대결까지 할 수 있게 한다(서버 저장·통계·낱말 모음은 다음 계획).

**Architecture:** 문제는 말 카드(JSON)에서 미리 만들어 얼려 둔 회차 파일을 읽는다. 채점·등급·대결 링크는 순수 함수(`src/lib/exam/`)이고, 화면은 클라이언트 상태 기계 하나(`ExamGame`)가 시작→문제→해설→채점→성적표를 넘긴다. 서버는 쓰지 않는다. 오늘 성적표·연속 응시는 기기 저장소에만 둔다.

**Tech Stack:** Next.js 16 App Router, TypeScript, Tailwind 4, vitest, Playwright E2E, `npx tsx` 스크립트. 새 의존성 없음.

**Spec:** `docs/superpowers/specs/2026-11-11-meme-exam-design.md` (실행자는 '한 판의 흐름', '시간제한과 점수', '성적표', '친구 대결', '힌트', '문제를 기계적으로 만들기' 절을 읽는다). 운영 규칙은 레포 `CLAUDE.md`.

## Global Constraints

- 이모지 금지(제목·버튼·링크·본문 모두). 아이콘은 `src/components/icons.tsx`의 `Icon`만.
- 디자인 토큰만 쓴다: `bg-paper` `bg-card` `bg-card-2` `border-line` `text-ink` `text-muted` `text-accent`. 글꼴 굵기 900 금지. 새 색 코드 금지.
- 누르는 것은 높이 44px 이상. 주 버튼은 `h-[52px] bg-ink text-paper rounded-full`.
- 가짜 숫자 금지: 정답률·상위 %·응시자 수는 이 계획에서 화면에 넣지 않는다(서버 집계가 생기는 다음 계획).
- 뱃지에 "신상", "최신", "요즘" 같은 말을 쓰지 않는다. `badge(when)`가 주는 글자만.
- 해설 문장은 카드의 `meaning`·`usage`·`origin`을 그대로 보여 준다. 화면 코드에서 문장을 지어내지 않는다.
- 태어난 해, 문제별 정오는 GA에 보내지 않는다. GA 값은 `isSafeValue`(숫자 4자리 이상 금지)를 통과해야 한다.
- "돌아가기"는 `useBackOrHome`. `router.back()` 금지.
- 새 문구에 KS X 1001 2350자 밖 한글이 있으면 `node scripts/font-subset.mjs`를 다시 돌린다.
- 검증 명령: `npm test`, `npm run test:e2e`, `npm run build`. 셋 다 통과해야 끝이다.
- 커밋은 사용자가 허락한 뒤에만 한다. 각 과제의 "커밋" 단계는 허락이 있으면 실행하고 없으면 건너뛴다.

## Review Focus

1. 문제를 푸는 도중 자정이 지나 날짜가 바뀐다 → 진행 중인 판은 시작한 회차로 끝까지 가고, 성적표도 그 회차로 저장된다(과제 5 테스트).
2. 손으로 고친 대결 링크(`/exam/meme/r/999-OOOOO-9999-0`, 글자 수 틀림, 없는 회차) → 일반 착지 화면으로 보이고 오류가 나지 않는다(과제 4·6 테스트).
3. 오늘 회차 번호가 얼려 둔 회차 수보다 크다 → 마지막 회차를 연다. 빈 화면이 되지 않는다(과제 2 테스트).
4. 기기 저장소를 못 쓰는 브라우저(사파리 개인정보 보호 모드, 인앱 브라우저) → 놀이는 그대로 되고 "오늘 이미 풀었어요"·연속 응시만 빠진다(과제 5 테스트).
5. 시간 초과와 보기 누르기가 거의 동시에 일어나거나, 보기를 두 번 빠르게 누른다 → 답은 한 번만 기록된다(과제 5 테스트).

export const LIMIT_MS = 10_000
export interface Answer { correct: boolean; msLeft: number; hint: boolean }
export function questionScore(a: Answer): number        // 오답 0. 정답 100 + round(20 * msLeft / LIMIT_MS). 힌트를 썼으면 가산 0

등급 표(설계 고정, 출시 뒤 바꾸지 않음): 5개 → 가산점 합이 50 이상이면 1, 아니면 2. 4개 → 40 이상 3, 아니면 4. 3개 → 30 이상 5, 아니면 6. 2개 → 7. 1개 → 8. 0개 → 9.

등급 별명(놀리지 않는 말, 설계자 초안): 1 `밈 고인물` · 2 `단톡방 통역사` · 3 `눈팅은 하는 사람` · 4 `반은 알아듣는 사람` · 5 `검색하며 따라가는 사람` · 6 `조카에게 배우는 중` · 7 `뉴스로 유행을 아는 사람` · 8 `한 박자 늦게 아는 사람` · 9 `오늘부터 시작하는 사람`.
