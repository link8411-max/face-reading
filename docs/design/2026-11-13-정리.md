# 디자인 개편 논의 정리 (2026-11-13)

하루 동안 주제가 여러 갈래로 벌어져서, 처음 하려던 일 기준으로 다시 묶었어요. 사이트 코드는 하나도 바꾸지 않았어요.

## 처음 하려던 일

**색과 메뉴(UX/UI) 개편.** 지금 디자인이 별로이고, 운세집 느낌이 아닌 요즘 흐름에 맞게 바꾸기.

## 사용자가 정한 것

- 베이지·바탕체 느낌에서 벗어나기. 경쟁 사이트가 아니라 디자인 시안 사이트를 보고 정하기.
- 핑크는 쓰지 않기.
- 애니메이션 넣기: 화면 진입, 결과 나오기 전 로딩, 결과 공개, 메뉴 이동.
- 해태·저승사자·무당 같은 우리 소재 캐릭터 넣기.
- 캐릭터 그림체는 ③번(극장판 애니메이션 화면 느낌). 유아용처럼 귀엽기만 한 건 아님.
- 캐릭터 구성은 취향이 아니라 사람들이 좋아하는 자료를 보고 추리기.
- 목적은 유입 늘리기. 번역을 넣어 해외 유입도 기대.

## 저녁에 확정한 것

시안 v4를 보고 "좋아, 이대로"라고 하셨어요. 그래서 아래를 확정으로 봤어요.

- **색**: B(블루·라임).
- **메뉴**: "홈 / 전체 / 오늘" 3탭과 홈 칩. ("UI 구성은 좋다"고 하심)
- **캐릭터**: 해태·저승사자·구미호·무당·백호·도깨비 여섯. ③번 화풍, 멤버 색 단색 배경.

설계 문서: `docs/superpowers/specs/2026-11-13-visual-revamp-design.md`

## 아직 안 정한 것

- **언제 사이트에 적용할지.** 11/12 판정(12/15까지 새 기능 중단)과 부딪혀요. 에이전트 셋은 12/16 이후를 권했어요.

## 곁가지로 나온 것 (보류)

- 가상 아이돌을 실사로 만들기: 아이디어 단계.
- 영어 페이지: 동물상 한 페이지로 수요부터 보자는 의견. 구글 검색 횟수는 광고 계정이 없어 못 봤어요.
- 손금: "보는 법" 검색이 월 2만 회 넘음. 글과 그림 고르기는 검색 작업, 사진 분석은 새 기능.

## 알게 된 사실

- 디자인·캐릭터는 검색 유입을 늘리지 못하고, 들어온 사람의 공유를 늘리는 쪽이에요(에이전트 셋 공통 의견).
- 색·글꼴만 바꿔도 8~12시간이 들어요. 테스트가 색을 고정하고 바탕체가 170곳에 쓰여요.
- 네이버 월간 검색: 오늘의운세 536만, 사주 9.3만, 관상 1만, 동물상테스트 2,570, 관상테스트 1,540.
- 해외 방문은 최근 28일 약 55세션이고 대부분 해외에 사는 한국어 사용자예요. 영어 페이지가 없어서 해외 검색 유입은 사실상 없어요.
