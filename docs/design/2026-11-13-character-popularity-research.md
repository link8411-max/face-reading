## 4. 실제 월간 검색 횟수 (네이버)

구글 트렌드 숫자는 0~100 상대 점수라 실제 횟수가 아니에요. 실제 횟수는 네이버 검색광고 API의 키워드 도구가 줘요.

- 지금까지 확인한 한 건(블랙키위, 2026-11-13): **구미호 월 9,320회**(PC 1,050, 모바일 8,270). 연관어 "구미호뎐" 14,400회, "인간 구미호" 25,470회.
- 블랙키위는 비회원 1분 1회에 조회마다 로봇 확인이 떠서 더 못 봤어요.
- 직접 수집: `node scripts/keyword-volume.mjs 구미호 도깨비 저승사자 해태 무당` (같은 공식 API를 직접 호출). `.env.local`에 `NAVER_AD_CUSTOMER_ID`·`NAVER_AD_API_KEY`·`NAVER_AD_SECRET`가 있어야 해요. 발급은 searchad.naver.com → 도구 → API 사용 관리. 키가 없어 아직 실행해 보지 못했어요.
- 구글(해외) 실제 횟수는 구글 광고 계정을 만든 뒤 키워드 플래너에서 봐요. 구글 광고 API는 개발자 토큰 승인이 필요해 더 번거로워요.

### 읽는 법

- 캐릭터 이름 자체를 검색해서 우리 사이트로 올 사람은 많지 않아요. 가장 깨끗한 숫자인 구미호가 월 9천, 저승사자가 4천대예요.
- 사이트 본업 검색어(관상테스트 1,540, 동물상테스트 2,570)도 작아요. "오늘의운세"는 536만으로 차원이 다르지만 경쟁이 가장 센 말이에요.
- 그래서 캐릭터는 "검색으로 사람을 데려오는 수단"이 아니라 "들어온 사람이 공유하게 만드는 수단"으로 봐야 해요. 고르는 기준도 검색량보다 호감과 닮은꼴 위험이 맞아요.

## 6. 손금 검색 수요와 경쟁 (2026-11-13)

"관상" 연관 검색어에서 손금이 나와서 따로 봤어요. 캐릭터와는 별개인 검색 유입 소재예요.

|---|---|---|

| 남자손금보는법 | 6,220 | 중간 |

| AI손금 | 185 | 중간 |
| 손금어플 | 115 | 중간 |

- 사람들이 찾는 건 "AI가 봐 주는 도구"가 아니라 "보는 법"이에요. 성별로 나눠 찾고(여자·남자), 모양 이름(일자·M자·막쥔)으로도 찾아요.
- 이미 있는 것: 해외 AI 손금 사이트·앱(Jenova, Media.io, Palmly, 앱스토어 "측정 카메라"), 국내 손금닷컴·제프의 손금연구소(이름 검색은 월 30~60회).
- 네이버 모바일 검색 결과(여자 손금 보는법, 손금)의 위쪽은 AI 브리핑, 클립, 지식iN, 카페, 블로그, 나무위키·위키백과였고, 손금 전문 사이트는 앞쪽 20개 링크 안에 없었어요. 네이버 자체 글이 자리를 차지하고 있어 바깥 사이트가 올라가기 쉽지 않아요.
- 만든다면 사진 분석 기능보다 글(여자 손금 보는 법, M자 손금 뜻, 일자 손금 뜻)이 수요에 맞아요.
