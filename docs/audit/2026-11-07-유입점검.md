## 2. 애드센스 반려 사유 (11/6 13:40 KST, 사이트 페이지 확인)

> **가치가 별로 없는 콘텐츠.** 사이트가 충분한 고유 가치를 제공하고, 웹에서 꾸준히 운영되며, 상업적 광고 파트너십을 지원하는 수준의 사용자 관심을 받고 있음을 보여야 합니다.

체크 3개: (1) 신뢰할 수 있는 고품질 정보·도구·서비스 (2) 지속적인 콘텐츠 유지관리 (3) **실제적인 사용자 관심**. Ads.txt는 '승인됨'으로 바뀌었다(10월의 '찾을 수 없음' 해결).

(3)이 핵심이다. 하루 20~40세션 사이트는 콘텐츠를 고쳐도 다시 떨어질 가능성이 높다. **지금 바로 재검토 요청하지 말고**, 아래 3·4번 작업으로 도구 페이지 본문을 채우고 하루 100세션 이상이 2~3주 유지된 뒤(현실적으로 12월 말~1월 신년운세 시즌 뒤) 요청하는 게 맞다. 그 사이 수익은 쿠팡 파트너스와 카카오 애드핏 신청(승인 문턱이 낮음)으로 버틴다.

## 3. 역할별 진단

### 3-1. SEO (기술·온페이지)

**이상 없는 것(직접 확인):** robots 전체 허용, 사이트맵 189개 전부 lastmod 있음, SSR로 본문이 HTML에 있음, 모든 핵심 페이지에 title·description·og:title·og:image·twitter:card가 페이지별로 다르게 들어 있음, 띠·MBTI·열전 페이지에 WebApplication·Article·BreadcrumbList·FAQPage JSON-LD 있음, 결과 공유 착지(/face2/r/blessing 등)는 "나는 복덕상이래. 너 관상도 봐줄까?" 같은 고유 og 제목 + 전용 og 이미지(/api/og/result). 404 정상. /unse와 /fortune/daily는 중복 아님.

참고: SEO 에이전트가 "ISFP 별명 '용감한 수호자'가 틀렸다"고 했는데 라이브 확인 결과 **우리 사이트는 ISFJ를 용감한 수호자, ISFP를 호기심 많은 예술가로 쓰고 있어 맞다.** 네이버 검색어 "용감한 수호자 isfp"는 검색자의 혼동이다. 조치 불필요.

### 3-2. AI 검색 노출 (AEO)

- 크롤러 차단 없음(GPTBot·ClaudeBot·PerplexityBot·Yeti 모두 200). JSON-LD·FAQ 이미 있음. **기술 기반은 충분.**
- 그런데 "무료 관상 테스트 사이트", "AI 관상 사이트 추천", "2027 말띠 운세", "삼국지 인물 테스트", "동물상 테스트 사이트" 5개 검색 모두 **미노출**(US 기반 웹검색 기준, 네이버·Perplexity 실측은 못 함). 대신 나온 건 숫자 있는 점수표(k-calc), 커뮤니티 소개글(Show GN/hada.news), 생년을 적은 브런치 글.
- 격차는 **"인용할 고유 사실"과 "남이 쓴 언급"**이다. 조치: 띠 페이지에 생년 표 + 질문형 H2("2027년 말띠 재물운은?") + 첫 3문장 요약, /samguk/people 허브에 "테스트란? 몇 명 중 매칭? 소요 시간? 무료?" Q&A + 인물 페이지 FAQPage(현재 Person·VideoObject만 있음), MBTI H2를 질문형으로. 그리고 **개발기 글 1~2편을 외부(Show GN·브런치·커뮤니티)에 게시**하는 쪽이 자사 사이트 손보기보다 효과가 클 수 있다.
- 지금의 "5개 쿼리 미노출"을 기준선으로 두고 2주 뒤 재측정.

### 3-3. 유입 채널·전환 (그로스)

**첫 방문 점검:** 홈 CTA는 하나로 좋고 "사진은 브라우저 안에서만"은 좋은 신뢰 포인트지만 부가 문구 수준. **/samguk는 업로드 전에 새는 링크가 20개 이상**(쇼츠 4개·긴 영상·운세 5종·궁합 3종)이라 가장 어수선하다. 띠·MBTI 페이지는 검색으로 들어온 사람이 읽고 나가는 **막다른 길**(얼굴 테스트로 보내는 본문 중간 CTA 없음, 공유 버튼 없음).

그로스 에이전트가 "og·공유 카드가 없을 수 있다"고 1순위로 꼽았는데 **직접 확인 결과 이미 결과별 고유 og 제목·이미지가 있다.** 이건 할 필요 없다. 대신 공유 뒤 착지 페이지(/samguk/r/<key> 등)에 "철수는 조운 82%. 너는?" + 시작 버튼 하나만 두는 **전용 착지 구조**인지 확인하고, 아니면 그렇게 바꾸는 게 K-factor에 직접 영향을 준다.
