# 부적 영상 녹화 시험표

시험 페이지: `/dev/bujeok-rec` (개발 전용, production 404). 6초 캔버스 애니메이션을 `captureStream(30)` + `MediaRecorder`로 녹화한다.

| 환경 | 지원 형식 | 녹화됨 | 저장됨 | 카톡으로 보내 재생됨 |
|------|-----------|--------|--------|----------------------|
| 데스크톱 크롬 | 확인 필요 | 확인 필요 | 확인 필요 | 확인 필요 |
| 안드로이드 크롬 | 확인 필요 | 확인 필요 | 확인 필요 | 확인 필요 |
| 아이폰 사파리 | 확인 필요 | 확인 필요 | 확인 필요 | 확인 필요 |
| 카카오톡 인앱(안드로이드) | 확인 필요 | 확인 필요 | 확인 필요 | 확인 필요 |
| 카카오톡 인앱(아이폰) | 확인 필요 | 확인 필요 | 확인 필요 | 확인 필요 |

메모: 개발 중 Claude 앱 내장 브라우저(Chromium 152)에서 `isTypeSupported`는 mp4·webm 모두 true였지만, 그 창은 `requestAnimationFrame`이 돌지 않아 녹화를 끝까지 확인하지 못했다. 그래서 데스크톱 행도 비워 둔다. 실제 크롬에서 확인할 것.
