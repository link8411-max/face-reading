# ep06 삼국지 속 고구려 — 컷 연출표와 그림 프롬프트 (대본 v2, 2026-11-05)

## 고정 화풍 문장 (모든 그림 요청에 그대로)
> 1990년대 코에이 삼국지풍 일러스트, 두꺼운 유화 붓 터치, 낮은 채도(흙빛·먹빛·짙은 녹색·바랜 붉은색), 한쪽에서 들어오는 빛과 깊은 그림자. 세로 9:16, 장면이 위아래 끝까지 꽉 참(빈 띠·여백·만화 칸 없음). 그림 안 글자·한자·숫자 없음. 서기 3세기 중엽. 피·상처·불타는 시체 없음. 인물은 실제 사람 비율. 얼굴과 핵심 행동은 화면 위쪽 20~60% 안(아래쪽은 자막 자리).

## 인물 고정 묘사 (리뷰어 검수 반영, 2026-11-05)
- **동천왕(위궁)**: 30대 중반 고구려 왕(209년생). 긴 얼굴, 짧은 콧수염, 날카로운 눈. 머리에 가는 새 깃 두 개를 위로 곧게 꽂은 작은 고깔 관(관 높이 이하, 인디언 깃털관 아님), 붉은 겉옷에 검은 띠, 통 넓은 바지, 가죽 장화, 등에 활 [연출: 새 깃 관·옷은 5세기 고분벽화 양식. 3세기 동이전은 "小加著折風，形如弁"].
- **고구려 무사**: 고깔 모양 절풍이나 둥근 쇠 투구, 작은 쇠비늘 갑옷(찰갑) [연출: 4~5세기 출토·벽화 근거], 긴 창·활. **말 갑옷 없음, 맨 말에 안장.**
- **고구려 주부 대가(G2)**: 중년, 검은 천 머리싸개(책, 동이전 "大加主簿頭著幘"), 짙은 갈색 겉옷. 왕과 다른 얼굴·옷(붉은 옷 금지).
- **사마의**: 59세. 넓고 각진 얼굴, 짙은 눈썹, 흰 가닥이 조금 섞인 검은 수염, 검은 관, 회흑색 포 위 쇠비늘 갑옷(끝 화면 초상 `public/images/samguk/사마의.jpg`에 맞춤).
- **관구검**: 40대 [연출: 생년 기록 없음]. 각진 얼굴, 짧은 검은 수염, 붉은 술 달린 투구, 검은 쇠비늘 갑옷. G4에만 나온다.
- **다른 위나라 장수(G6·G8)**: 관구검과 다른 사람. 50대, 둥근 얼굴, 수염 거의 없음, 술 없는 검은 투구.
- **위나라 군**: 검은·남색 계열 갑옷, 검은 깃발(글씨 없음, 편 공용 색).
- **밀우**: 갑옷 입은 중년 고구려 무사. **유유**: 수수한 흰 포의 중년 신하.
- 크기: 모두 실제 사람 비율. 말 위 장수도 옆 기병과 같은 크기.

## 그림 프롬프트 (고정 화풍 문장 + 인물 묘사 + 아래)
- **G1** 산 위 다듬은 돌로 쌓은 낮은 성벽(산성) 위에 동천왕이 서서 아래 골짜기를 내려다본다. 성벽 높이는 왕의 허리, 기와 누각·톱니 여장 없음. 상반신과 얼굴이 크게. 뒤로 겹겹 깊은 산과 골짜기(원문 "多大山深谷"). 아침 빛. 날카로운 눈이 화면 위쪽 1/3.
- **G2** 요동 들판의 위나라 군막 앞. 의자에 앉은 사마의 앞에, 고구려 주부 대가가 선 채로 두 손을 앞에 모아 고개를 살짝 숙여 인사한다(공수). 사마의는 앉은 채 받는다. 뒤로 고구려 기병 수십이 맨 말 위에 줄지어 있다. 위나라 검은 깃발(글씨 없음). 맑은 낮.
- **G3** 해 질 녘, 강 하구 평지의 낮은 흙 성(서안평, 성벽 높이 사람 키 2배, 누각 없음). 고구려 기병 무리가 활을 들고 성 쪽으로 달려든다. 먼지, 말발굽. 피·쓰러진 사람 없음. 기병 선두의 얼굴이 화면 위쪽.
- **G4** 초가을, 깊은 산골짜기 사이 길을 위나라 군이 긴 줄로 행군한다. 앞에 말 탄 관구검이 앞을 노려본다(말과 사람은 옆 기병과 같은 크기). 위나라 검은 깃발 여럿(글씨 없음). 흐린 하늘.
- **G4b** 넓은 강가 들판. 고구려 기병들이 등을 보이며 골짜기 쪽으로 흩어져 물러나고, 멀리 위나라 검은 깃발 대열이 다가온다. 쓰러진 사람·피 없음. 흙먼지, 흐린 하늘.
- **G5** 늦가을 가파른 산비탈. 위나라 병사들이 말 고삐를 짧게 쥐고 걸어서 말을 끌고 오른다. 빈 나무 수레 하나를 밧줄로 벼랑 위로 끌어올린다(원문 "束馬縣車"; 말은 매달지 않음). 산꼭대기에 다듬은 돌로 쌓은 낮은 성벽(환도성, 사람 키 3배, 기와 누각·현판 없음). 불·연기·시체 없음.
- **G6** 늦가을 깊은 산 속 큰 바위 앞. 위나라 병사가 등을 보이고 정과 망치로 바위를 친다. 병사의 몸과 팔이 새기는 면을 가리고, 정 끝에서 돌가루만 튄다. 보이는 바위 면은 거친 맨돌. 뒤에 말 탄 위나라 장수(관구검 아님: 둥근 얼굴, 수염 거의 없음, 술 없는 투구)가 지켜본다.
- **G6b** 강가(비류수). 고구려 기병이 활과 창을 들고 위나라 보병 대열을 밀어붙이고, 위나라 병사들은 방패를 든 채 뒤로 물러난다. 기세가 고구려 쪽(화면 위쪽 왼편). 쓰러진 사람·피 없음.
- **G7** 좁은 산길 고갯마루. 갑옷 입은 중년 고구려 무사 밀우가 창을 들고 병사 4명과 길을 막아서 카메라 쪽을 본다(모두 같은 사람 크기). 밀우 뒤, 골짜기 아래로 말 탄 왕과 기병 5명이 멀어진다. 화면 아래쪽 앞 가장자리에 위나라 검은 깃발 끝 두세 개만 보인다. 피 없음.
- **G8** 위나라 군막 안. 흰 포의 중년 고구려 신하 유유가 무릎을 꿇고 뚜껑 닫힌 청동 합(지름 약 20cm)을 두 손으로 받쳐 올린다. 앞에 위나라 장수(관구검 아님: 50대, 둥근 얼굴, 수염 거의 없음, 투구는 탁자 위)가 거만하게 내려다본다. 유유의 눈은 차분하고 단단하다. 칼은 보이지 않는다. 청동 기름 접시 등잔 빛, 긴장된 분위기.
- **G9** 이른 아침, 낮게 깔린 흰 안개(위로 오르는 연기 없음). 세 갈래 골짜기에서 고구려 기병이 동시에 쏟아져 내려온다. 아래 평지에서 위나라 병사들이 서서 방향을 잃고 흩어지거나 뒤돌아 달아난다. 땅에 누운 사람 없음. 넓은 부감.
- **G10** 어두운 서재 탁자 위. 왼쪽에 끈으로 묶어 말아 둔 대나무 죽간 묶음, 오른쪽에 실로 꿰맨 고서 한 권(덮여 있고 표지에 글씨 없음). 가운데 청동 기름 접시 등잔 하나. 사람 없음.
