## 지도 영역 근거 (2026-11-05 사용자 요청: 고구려 영역 크기)
- 고구려: 정사 동이전 "都於丸都之下，方可二千里，戶三萬". 영역은 국사편찬위원회 우리역사넷·국사 교과서 '여러 나라의 성장'(기원 전후~3세기) 지도의 고구려 표기 범위(졸본·국내성~백두산, 압록강 남북 산간)를 따랐다. 교과서도 국경선을 긋지 않으므로 대략 영역으로만 칠한다.
- 옥저: "國小，迫於大國之間，遂臣屬句麗" / "使大加統責其租稅" → 점선·연한 색 '복속'.
- 동예: "漢末更屬句麗" → 점선·연한 색 '복속'.
- 요동·낙랑(평양 일대): 238년 이후 위나라 군현 → 위 색. 238년 동맹 지도에서는 요동·낙랑이 공손씨(회색).
