# 삼국지 쇼츠 제작 템플릿 (v2, 2026-11-04)

모든 편은 이 틀을 그대로 따른다. 편마다 새로 정하는 건 **이야기 내용과 컷 그림**뿐이다.

## 1. 한 편의 구조 (약 60초, 6박자)

| 박자 | 초 | 역할 | 해설 말투 | 화면 |
|---|---|---|---|---|
| 훅 | 0–3 | 가장 유명한 순간, 한가운데서 시작 + 질문 한 마디 | "이 장면, 다들 아시죠?" | 클로즈업, 움직임 중 |
| 이야기 | 3–25 | 다들 아는 그 이야기를 **그냥 들려준다** (토 달지 않음) | 이야기꾼 | 이어지는 체인 2~3개 |
| 반전 | 25–30 | **한 편에 딱 한 번** 뒤집는 한 줄 | "그런데요, 역사책을 펼치면…" | 먹이 번지며 멈춤 |
| 기록 | 30–48 | 기록에 남은 사실 2~3개, 하나씩 보여 준다 | 담담하게 | 체인 2개 |
| 마무리 | 48–55 | 사람 냄새 나는 한 줄 + 다음 편 고리 | "그리고 이 의리가…" | 체인 1개, 멈춤 |
| 끝 화면 | 55–62 | 닮은꼴 / 월드컵 안내 | 질문 한 마디 | 초상화 |

**출처 표시 규칙:** 해설에서 "연의에서는 / 정사에는"을 반복하지 않는다. 반전 박자에서 한 번만 말한다.
대신 화면 오른쪽 위에 **도장 배지**(`연의` 붉은색 / `정사 · 관우전` 푸른색)를 박자 단위로 붙인다. 배지가 말하고, 해설은 이야기한다.

## 2. 화면 문법 (이어지는 영상)

- **컷을 따로 만들어 붙이지 않는다.** 박자마다 Flow에서 **체인**으로 만든다: 기준 컷(그림→영상) → `Extend`(같은 공간에서 이어 찍기) 1~2번. 장소가 바뀌면 `Jump To`(같은 인물, 새 장소).
- **이음 요소:** 체인과 체인 사이는 반드시 같은 물건·움직임으로 잇는다(꽃잎→꽃잎, 잔→잔, 촛불→횃불, 문이 열림→들어옴). 컷 목록에 `link` 칸으로 적는다.
- **인물 고정:** 인물마다 기준 그림 3장(얼굴·상반신·전신)을 `docs/videos/characters/<이름>/`에 두고 Flow `Ingredients`로 등록해 모든 편에 재사용한다. 한 번 만들면 다시 안 만든다.
- **카메라:** 천천히 밀고 당기기, 느린 옆 이동만. 휙 도는 카메라 금지(화풍이 깨진다).
- **컷 길이:** 체인 하나 8~16초, 그 안의 컷 3~6초.
- **폭력:** 맞는 순간은 손으로 감싸기·실루엣·물건(쓰러진 잔, 꺼지는 등불)으로. 피·상처·클로즈업 금지.
- **글자:** 그림·영상 안에 글자 금지. 모든 글자는 조립 단계에서 얹는다.

## 3. 제작 순서 (확인은 세 번)

1. **대본** `episode.json`: 6박자 해설 + 출처 배지 + 컷 목록(체인·이음 요소) → **확인 ①**
2. **콘티**: 컷마다 키프레임 그림 1장(Gemini, 화풍 기준 + 인물 기준 첨부), 한 장으로 모아 → **확인 ②**
3. **체인 생성**(Flow): 기준 컷 → Extend/Jump To. 이음새의 끝 프레임·첫 프레임을 눈으로 확인.
4. **해설**: TTS 한 번 → 쌍 쉼으로 나누기 → 실제 쉼 위치로 단어 시간 맞추기(`align.mjs`).
5. **조립**(Remotion): 체인 영상 + 단어별 자막(핵심어 금색) + 제목 띠 + 출처 배지 + 전환 효과음 + 깔림 소리.
6. **검수**: 0.25초 프레임 검수(되감기·피), 스토리보드(흐름·인물 연속성) → **확인 ③** → 업로드.

## 6. 업로드 글 규칙
- **제목**: 인물 이름을 앞에 쓴다("유비·관우·장비 도원결의, 정말 의형제를 맺었을까?"). 검색어가 되는 이름·사건명 + 질문 + `#삼국지 #shorts`.
- **설명**: 첫 줄에 인물 이름과 사건을 다시 쓰고, 출처 2줄(연의/정사), 시리즈 표시와 다음 편, 사이트 안내("→ 채널 프로필 링크"), 해시태그에 인물 이름 각각.
- **인스타 캡션**: 같은 내용에 이모지 한 개, `#릴스`.
- 자막은 문구 단위(단어별 하이라이트 금지 — TTS 단어 시간이 부정확해 어긋나 보인다). 핵심어만 금색 고정.

## 7. 비용 (한 편)
기준 컷 ~6 + Extend/Jump ~6 = 12회 × Veo 3.1 Lite 10크레딧 ≈ 120, 다시 뽑기 포함 ≈ 150. 월 1,000크레딧이면 6편.
TTS는 편당 1회(모델당 하루 10회).
