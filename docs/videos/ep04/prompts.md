```
[화풍] 첨부한 1~2번째 그림과 완전히 같은 화풍으로 그려 줘. 1990년대 코에이 삼국지 게임의 일러스트처럼, 두꺼운 유화 붓 터치, 검은 외곽선 없음, 낮은 채도(흙빛·먹빛·짙은 녹색·바랜 붉은색), 한쪽에서 들어오는 극적인 빛과 깊은 그림자. 사진처럼 보이는 실사 표현, 3D 렌더 느낌, 애니메이션 셀 느낌은 금지.
[비율] 세로 9:16 한 장. 중요한 인물·얼굴은 화면 위쪽 2/3 안에 둔다(아래 1/3에는 나중에 자막이 올라간다).
[인물 비율] 모든 사람은 실제 사람 비율이다. 머리:몸 = 1:7~7.5. 거인, 과장된 근육, 과장된 어깨, 과장된 무기 크기는 금지. 관우는 키 약 2m라서 보통 사람(170cm 안팎)보다 머리 하나 정도 클 뿐이다.
[시대] 서기 219~220년 중국 후한 말. 건물은 흙벽·나무 기둥·기와, 갑옷은 쇠비늘(찰갑)과 가죽, 옷은 소매 넓은 한복식 포. 명·청나라 양식(변발, 청나라 관모, 화려한 자금성 건물), 일본식 갑옷, 서양식 등잔·랜턴은 금지.
[계절·날씨] 한겨울(음력 12월~1월)이다. 하지만 기록에 눈이 없으므로 눈, 눈송이, 쌓인 눈, 얼음 고드름은 그리지 않는다. 겨울 느낌은 잎이 다 떨어진 나무, 누렇게 마른 풀, 차가운 푸른빛 공기, 사람 입에서 나오는 옅은 입김으로만 낸다.
[금지] 그림 안의 글자·한자·간판 글씨·깃발 글씨·서명·로고·워터마크·테두리 금지. 피, 상처, 잘린 몸, 시체 금지.
```

```
(공통 머리말) (관우 고정 묘사)

빛: 왼쪽 아래 성벽 횃불 하나에서 오는 따뜻한 주황빛이 붉은 얼굴의 한쪽을 비추고, 반대쪽은 차가운 푸른 밤빛과 깊은 그림자.
배경: 흐릿하게 보이는 성벽 여장(톱니 모양 담)과 축 처진 깃발 두어 개(글씨 없음), 그 너머 잎 없는 나무가 선 어두운 들판과 산 능선. 하늘은 구름 낀 짙은 남색, 달빛이 구름 뒤에서 희미하다.
표정: 지쳤지만 꺾이지 않은 얼굴. 눈썹 사이에 깊은 주름.
금지: 눈송이, 쌓인 눈, 거대한 체구, 화려한 금빛 갑옷 장식 과다.
```

### K08 · 정사 — 허수아비 세우고 탈출 (새 컷)
- 해설: "그런데 실제 기록은 달라요. 항복하는 척, 성 위에 허수아비를 세우고, 몰래 빠져나와요. 남은 건 기병 열댓."
- 근거: 정사 오주전 "羽偽降，立幡旗為像人於城上，因遁走，兵皆解散，尚十餘騎"
- 꼭 보여야 할 것: 성벽 위의 깃발과 사람 모양 인형 줄(보초처럼 보임), 뒷문으로 빠져나가는 기병 열댓. 인형 재료는 기록에 없으니 짚을 강조하지 않는다.

**그림 프롬프트**
```
(공통 머리말) (관우 고정 묘사: 작게 보이므로 녹색 전포·붉은 얼굴·긴 수염·언월도만 알아보이면 된다)
장면: 한겨울 밤, 달빛이 구름 사이로 희미하게 비치는 작은 흙벽 성(맥성). 눈 없음, 땅은 마른 흙과 누런 마른 풀.
성벽 위: 일정한 간격으로 깃발(글씨 없음, 바랜 녹색)이 꽂혀 있고, 그 사이사이에 투구를 씌우고 창을 기대 세운 사람 모양 인형들이 보초처럼 줄지어 서 있다. 멀리서 보면 병사 같지만, 가까운 두세 개는 얼굴이 천으로 감싼 둥근 덩어리라 사람이 아닌 것이 살짝 드러난다. 성벽 위에 진짜 사람은 없다.
성벽 아래: 화면 오른쪽 아래, 성 뒤쪽의 작은 나무 문이 반쯤 열려 있고, 말 탄 기병 열댓 명이 한 줄로 조용히 빠져나간다. 맨 앞은 녹색 전포의 관우(언월도를 비스듬히 멤). 횃불은 하나도 없다. 말발굽 아래로 마른 흙먼지가 조금.
구도: 성벽 바깥쪽 비스듬히 높은 곳에서 내려다본 구도. 성벽 높이는 사람 키의 세 배 정도, 사람과 말은 실제 크기로 작게.
빛: 차가운 달빛(푸른 회색)만. 성벽 그림자가 길게 드리운다.
금지: 눈, 쌓인 눈, 횃불 든 기병, 수백 명의 군대(열댓 명만), 성벽 위 진짜 병사.
```

```
3~8초: 카메라가 성벽 위에서 아래 뒷문 쪽으로 아주 천천히 내려간다. 뒷문으로 기병 열댓 명이 한 명씩 소리 없이 빠져나가 어둠 속 들판으로 멀어진다.
```

### R1 · 정사 — 밤 산길을 달리는 열댓 기 (교체: 기존 retreat는 눈밭에 보병 무리)
- 근거: 정사 "尚十餘騎" · 연의 77회 북문에서 산길 "此去皆是山僻小路，可通西川", 밤 "初更以後"
- 꼭 보여야 할 것: 지친 관우와 적은 수의 기병, 좁은 산길.

**그림 프롬프트**
```
(공통 머리말) (관우 고정 묘사)
장면: 한겨울 밤, 잎 없는 나무와 바위가 양쪽에 선 좁은 산길. 눈 없음, 길은 마른 흙과 낙엽.
관우가 말을 타고 맨 앞에서 달려온다(화면 위쪽 가운데, 카메라 쪽으로 비스듬히). 지친 얼굴, 수염과 녹색 전포가 바람에 뒤로 날린다. 언월도를 오른손에 비스듬히 들었다.
뒤에 관우보다 젊은 장수 한 명(관평: 20~30대, 수염 없거나 짧음, 은빛 쇠갑옷, 붉은 술 달린 투구)과 기병 열 명 남짓이 한 줄로 따른다. 모두 지쳐 고개가 숙여져 있다.
```

```
소리: 바람, 군막 천이 흔들리는 소리, 멀리 말 울음.
```

### K11 · 연의 — 주인을 잃은 적토마 (새 컷)
- 해설: "주인을 잃은 적토마는 며칠을 굶다 죽고,"
- 근거: 연의 77회 "赤兔馬被馬忠所獲，獻與孫權。權即賜馬忠騎坐。其馬數日不食草料而死" · 적토마 털빛 연의 3회 "渾身上下，火炭般赤，無半根雜毛"(온몸이 숯불처럼 붉고 잡털 하나 없음)
- 꼭 보여야 할 것: 여물에 입을 대지 않는 적토마. 죽는 장면은 보여 주지 않는다(쓰러지려는 데서 끝).

**그림 프롬프트**
```
(공통 머리말)
장면: 한겨울 해 질 녘, 오나라 군영의 허름한 마구간. 나무 기둥과 짚 지붕, 바닥은 마른 짚. 마구간 틈으로 비스듬히 들어오는 차가운 주황빛 저녁 햇살. 눈 없음.
적토마: 화면 가운데, 온몸이 숯불처럼 붉은 털(잡털 없음)의 크고 잘생긴 말. 굴레와 고삐가 기둥에 묶여 있다. 고개를 깊이 떨군 채 눈을 반쯤 감고 서 있고, 갈비뼈가 조금 드러날 만큼 야위었다. 갈기가 흐트러져 있다.
말 앞의 나무 여물통에는 여물과 콩이 가득한데, 손댄 흔적이 없다.
사람 없음.
구도: 말 옆얼굴과 여물통이 함께 보이는 중간 거리, 말의 눈이 잘 보이게.
빛: 등 뒤에서 들어오는 낮은 햇빛이 붉은 털 가장자리를 빛나게 하고, 얼굴 쪽은 그늘.
금지: 쓰러지거나 죽은 말, 피, 사람, 눈.
```
**영상 프롬프트**
```
(영상 공통 머리말)
0~3초: 적토마가 고개를 떨군 채 가만히 서 있고, 여물통 쪽으로 코를 한 번 가져갔다가 먹지 않고 다시 고개를 돌린다.
3~6초: 말이 천천히 눈을 감는다. 들어오던 저녁 햇빛이 조금씩 어두워진다.
6~8초: 말의 앞다리가 아주 천천히 꺾이며 몸이 낮아지기 시작하는 데서, 화면이 어두워진다(쓰러지는 장면은 보이지 않는다).
카메라: 고정.
소리: 바람, 짚이 바스락거리는 소리, 말의 약한 숨소리.
```

### K09 — 그대로 (훅에서 기준 컷, after 박자에서 연장 사용)

### L1 수정 — 성도 유비의 방, 꺼졌다 다시 켜지는 등불 (장소 변경)
- 해설: "…그 맹세가, 이제 유비를 움직여요."
- 근거: 연의 77회 유비의 꿈 "室中忽起一陣冷風，燈滅復明" · 유비는 성도에 있음(219년 한중왕, 성도). 등불은 후한식 청동 등잔.
- 꼭 보여야 할 것: 사람 없는 방, 등불이 꺼졌다가 다시 켜진다. 관우의 귀신은 그리지 않는다.

**그림 프롬프트**
```
(공통 머리말)
장면: 한겨울 밤, 성도에 있는 유비의 침소. 나무 기둥, 엷은 휘장, 낮은 책상 위에 죽간 두루마리 몇 개와 후한 시대의 청동 등잔(받침 위 얕은 기름 접시에 심지 하나, 유리 없음) 하나가 작게 타고 있다. 책상 옆 벽걸이에 녹색 전포 한 벌이 걸려 있다(관우를 떠올리게 하는 소품, [연출]). 휘장 너머 침상은 어둠 속에 흐릿하다. 사람은 보이지 않는다.
빛: 등잔 불꽃 하나의 따뜻한 주황빛, 나머지는 짙은 어둠과 차가운 푸른 밤빛. 창문 종이 너머 잎 없는 나뭇가지 그림자.
금지: 귀신·유령·반투명 인물, 유리 랜턴, 눈, 글자.
```
**영상 프롬프트**
```
(영상 공통 머리말)
0~2초: 등잔 불꽃이 조용히 탄다.
2~4초: 어디선가 찬 바람이 한 줄기 불어 휘장과 벽의 녹색 전포 자락이 크게 흔들리고, 등잔 불이 훅 꺼져 방이 어두워진다.
4~6초: 어둠 속에서 가는 연기 한 줄.
6~8초: 꺼졌던 등잔 심지에 불이 저절로 천천히 다시 살아나 방이 다시 밝아진다. 휘장은 조용해진다.
카메라: 고정.
소리: 바람, 불꽃이 꺼지는 작은 소리, 정적, 다시 불붙는 작은 소리.
```
