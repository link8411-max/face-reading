# 연출 지시서 — 대본·그림·영상 단계마다 Claude가 쓴다 (2026-11-05)

Gemini·Veo는 적힌 것만 지키고, 적히지 않은 건 마음대로 채운다. 그래서 **안 적은 것은 틀린다**고 보고, 컷마다 아래 항목을 빠짐없이 쓴다.
ep04에서 실제로 틀린 것: 거인 관우, 손바닥만 한 머리 상자, 기록에 없는 눈, 경첩이 반대인 뚜껑과 사라지는 뚜껑, 상자에서 솟는 연기·불, 섬뜩하게 웃는 조조, 발밑 초록 기운, 서양식 유리 와인잔·랜턴, 명·청식 성문과 현판 글씨, 여물을 먹는 '굶은' 적토마, 연의 장면에 붙은 정사 배지.

## 1. 대본 단계 — 컷 연출표 (`epNN/direction.md`)

컷마다 한 칸씩:

| 항목 | 쓰는 법 |
|---|---|
| 해설 | 이 컷 동안 나오는 문장 |
| 출처 배지 | 이 컷의 내용 출처(정사 ○○전 / 연의 ○회 / 연출). 한 박자 안에서 출처가 바뀌면 컷을 나눈다 |
| 근거 | `factcheck.md`의 원문 인용 줄 |
| 화면에 꼭 보일 것 | 해설이 말하는 것을 그대로(예: "굶다 죽고" → 여물통에서 고개를 돌린 야윈 말) |
| 보이면 안 되는 것 | 해설과 반대로 읽히는 것(예: 먹는 모습), 결과를 미리 보여 주는 것 |
| 시작 상태 → 끝 상태 | 컷 첫 프레임과 마지막 프레임의 상태(뚜껑 닫힘 → 열림, 서 있음 → 주저앉음) |
| 자막 영역 | 화면 아래 65~80%에 자막. 얼굴·핵심 소품은 위쪽 20~60%에. 맨 위 15%는 제목 띠 |
| 이어지는 것 | 앞 컷과 같은 인물이면 옷·관·수염·말 색을 같게 적는다 |

## 2. 그림 단계 — Gemini 프롬프트에 반드시 넣을 것

1. **공통 머리말**(화풍·비율·시대·계절·금지) — `epNN/prompts.md` 0-1.
2. **인물 고정 묘사**: 나이, 키(옆 사람과의 비교로: "보통 사람보다 머리 하나 큼"), 얼굴색, 수염 길이·색, 관·두건, 옷 색, 무기 크기. 실존 이름 대신 외모로.
3. **물리 명세**(물건이 있으면 꼭):
   - 누가 어디에 서 있고 어느 쪽을 보는지(화면 왼쪽/오른쪽, 카메라 쪽/반대쪽)
   - 손이 무엇을 어떻게 잡는지
   - 문·뚜껑·상자: **경첩은 여는 사람 반대편, 뚜껑은 여는 사람 반대쪽으로 열린다**, 크기(cm), 안이 보이는지
   - 인원수(정확한 숫자), 말의 색과 수
   - 크기 비교: 성벽 = 사람 키의 몇 배, 상자 = 사람 머리가 들어갈 크기
4. **시대 소품**: 등잔은 청동 기름 접시, 잔은 사발(굽 달린 유리잔 금지), 건물은 후한식(벽돌 누각·현판 금지).
5. **금지 목록**: 글자, 피·상처처럼 보이는 붉은·갈색 얼룩, 눈(雪), 연기·불·빛·마법 효과, 유령, 웃음(장면에 따라).
6. 그림을 받으면 **Claude가 위 항목을 하나씩 대조**하고, 이어서 **리뷰어(아래 4)** 를 돌린 뒤에만 사용자에게 보인다.

## 3. 영상 단계 — Flow(Veo) 프롬프트에 반드시 넣을 것

1. 영상 공통 머리말(그림체 유지, 글자·말소리 금지, 느린 카메라, 컷 바뀜 금지).
2. **첫 프레임 상태와 끝 상태**를 그림 그대로 다시 적는다.
3. **초 단위 동작**(0~3초 / 3~6초 / 6~8초), 한 컷에 동작은 하나만.
4. **변하면 안 되는 것 목록**: 인물 수, 얼굴, 옷, 관(머리에서 떨어지지 않음), 뚜껑은 경첩에 붙은 채, 말 색, 소품 위치.
5. **금지 효과**: 연기·불길·빛줄기·마법 기운·바람에 날아가는 천·형체 녹음.
6. 실존 인물 이름 금지(외모로). 받은 클립은 0.25초 간격으로 보고, 쓸 구간만 잘라 쓴다(`cut_clips*.sh`에 이유를 주석으로).

## 4. 리뷰어 — 단계마다 한 번

Claude 혼자 보면 놓친다(ep04 상자 뚜껑을 두 번 놓쳤다). 대본 표, 그림 묶음, 조립본이 나올 때마다 **독립 서브에이전트**에게 파일만 주고(내 판단은 주지 않음) 이 문서의 체크리스트로 검수시킨다.
- 보고 형식: 치명/중간/사소, 시각(초), 근거 프레임, 고칠 방법.
- 치명 0건이 될 때까지 고치고 같은 리뷰어에게 다시 보인다. 그다음에만 사용자에게 보낸다.
