# 밈 능력고사 1회차 초안 (2026-11-11)

사용자가 읽고 확정하기 전의 초안이다. 구성: 낱말 3 + 상황 밈 2, 난이도 쉬움 2·보통 2·어려움 1. 해설은 전하는 말투("~래요", "~라고 해요").

출처 확인: 낱말 셋은 쓰레드 글 2개 이상 + 네이버 검색 요약이 일치. 상황 밈 둘은 서로 다른 블로그 글 2개의 본문을 읽고 썼다.

## 1. 막나귀 (낱말 · 쉬움)

- 지수: 야 7시 강남역 맞지? 나 지금 나간다
- 나: 화장까지 다 했는데 갑자기 `____` 왔어…
- 보기: **막나귀** / 갑통알 / 스불재 / 오운완
- 맞으면 지수: ㅋㅋㅋ 그래도 나와. 나오면 재밌잖아
- 틀리면 지수: 응? 그게 무슨 말이야. 오는 거 맞지?
- 시간 초과 지수: 읽씹이야? 나 출발했다고
- 이런 말이에요: '막상 나가려니 귀찮다'를 줄인 말이래요.
- 이럴 때 써요: 약속은 잡아 놨는데 나갈 시간이 되자 갑자기 귀찮아질 때 써요. "운동 가야 하는데 막나귀 왔어."
- 어디서 나왔나: 세 마디의 앞 글자를 딴 줄임말이에요. 소리가 '당나귀'와 비슷해서 말장난으로도 쓴대요.

## 2. 연락 없네 잘 살아 (상황 밈 · 쉬움)

- 카드: "37분째 답 없네. 잘 살아."
- 질문: 이 말의 진짜 속뜻은?
- 보기: **빨리 답장하라는 장난 섞인 투정** / 정말로 헤어지자는 통보 / 바쁘니 나중에 연락하자는 인사 / 멀리 이사 간다는 소식
- 이런 말이에요: 답장이 조금 늦었을 뿐인데 영영 헤어지는 것처럼 부풀려 말하는 장난이래요.
- 이럴 때 써요: 답이 늦거나, 올린 글에 반응이 없을 때 써요. '시간 + 연락 없네 + 잘 살아' 꼴이에요. "올린 지 10분인데 아무도 반응 없네. 잘 살아."
- 어디서 나왔나: 2026년 늦여름부터 릴스와 X에서 퍼졌다고 해요. 처음 쓴 사람은 확인하지 못했어요.

## 3. 젬민이 (낱말 · 보통)

- 민재: 저녁 메뉴 아직도 못 정했어?
- 나: 응, 제미나이한테 물어보는 중. 나 요즘 완전 `____` 됐어
- 보기: **젬민이** / 테무인간 / 동엽이 / 엠비스찬
- 맞으면 민재: ㅋㅋ 내일 입을 옷도 물어본다며
- 틀리면 민재: 응? 그게 뭔데
- 시간 초과 민재: 메뉴 고르다 잠들었어?
- 이런 말이에요: 사소한 결정까지 AI에게 맡기는 사람을 가리키는 말이래요.
- 이럴 때 써요: 점심 메뉴나 옷차림까지 AI 답대로 정하는 자기 모습을 웃으며 말할 때 써요. "여행 일정도 AI가 짜 줬어. 나 젬민이야."
- 어디서 나왔나: 구글의 AI '제미나이'에서 온 말이라고 해요.

## 4. 전여친 감자칼 (상황 밈 · 보통)

- 카드: "전여친 감자칼"
- 질문: 어떤 사연에서 나온 말일까요?
- 보기: **헤어진 연인이 오랜만에 연락해, 예전에 쓰던 감자칼을 구해 달라고 했다** / 이별 선물로 감자칼을 받았다 / 감자칼 광고에 헤어진 연인이 함께 나왔다 / 요리 대회에서 헤어진 연인끼리 감자 깎기로 겨뤘다
- 이런 말이에요: 헤어진 연인이 오랜만에 연락해서 부탁한 것이 평범한 감자칼이었다는 사연에서 나온 말이래요.
- 이럴 때 써요: 헤어져도 잊히지 않는 물건을 두고 농담할 때 써요. "전여친도 못 잊은 감자칼"처럼요.
- 어디서 나왔나: 2026년 10월 스레드에 올라온 사연이라고 해요. 먼저 돌던 '전남친 토스트'의 짝으로 불려요.
- 메모: "6년 만에"는 옮겨지면서 붙은 표현이라는 글이 있어 쓰지 않았다.

## 5. 오디세이 (낱말 · 어려움)

- 하준(초등학생 조카): 이모 나 오늘 완전 오디세이야
- 나: `____` (알아들은 척 답장하기)
- 보기: **또? 이는 닦았어?** / 영화 재밌었어? / 멀리 다녀오느라 힘들었겠다 / 오디션 붙었어?
- 맞으면 하준: 헐 이모 어떻게 알았어. 푸딩이랑 마카롱이랑 아이스크림 먹었어
- 틀리면 하준: 이모… 그 오디세이 아니거든
- 시간 초과 하준: 이모 모르는구나? 검색하고 있지
- 메모(사용자 지적 2026-11-11): 처음 초안은 "그게 무슨 뜻인데?" → 뜻 고르기였는데 뻔하고 재미없다고 함. 뜻을 묻게 하지 말고, 알아들은 사람만 할 수 있는 답장을 고르게 한다.
- 이런 말이에요: '오늘 디저트 세 개 이상 먹음'을 줄인 초등학생 유행어래요.
- 이럴 때 써요: 단것을 잔뜩 먹은 날 자랑하듯 써요. "푸딩에 마카롱에 아이스크림까지, 나 오늘 오디세이."
- 어디서 나왔나: 2026년 11월 유병재 유튜브의 아일릿 영상에서 초등학생이 소개해 알려졌다고 해요. 같이 나온 말이 '빼난지원금'이에요.
- 메모: 같은 이름의 영화가 화제라 헷갈리는 점이 재미. 보기 3번이 그 함정.

## 확정 전 확인할 것

- 1번·3번의 오답 보기는 실제로 쓰이는 다른 말이다(지어낸 말 아님).
- 5번의 유래(영상 날짜·채널)는 네이버 요약과 기사 제목으로만 확인했다. 영상을 직접 보지 않았다.
- 2번 예문의 "37분"은 출처 글 제목의 숫자를 빌렸다.
